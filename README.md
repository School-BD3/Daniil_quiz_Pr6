# Вікторина - Flutter State Management

## Загальна інформація

- **Практична робота:** 6.1 - State Management, частина 1
- **Варіант:** 4 — Вікторина
- **Технології:** Flutter, Dart
- **Керування станом:** `setState`, `ChangeNotifier`, `InheritedNotifier`
- **Сторонні бібліотеки для керування станом:** не використовуються

## Функціональність

Застосунок реалізує вікторину з питаннями та варіантами відповідей.

- Відображення питань і варіантів відповідей.
- Вибір відповіді з візуальним виділенням.
- Підтвердження вибраної відповіді окремою кнопкою.
- Відображення правильності підтвердженої відповіді.
- Відображення поточного номера питання та рахунку.
- Екран результатів із відсотком правильних відповідей і переліком помилок.
- Можливість пройти вікторину повторно без перезапуску застосунку.

## Запуск проєкту

Необхідно встановити Flutter SDK та Git.

1. Клонувати репозиторій:

   ```bash
   git clone <URL_РЕПОЗИТОРІЮ>
   ```

2. Перейти до каталогу проєкту:

   ```bash
   cd flutter_application_quiz
   ```

3. Отримати залежності:

   ```bash
   flutter pub get
   ```

4. Перевірити проєкт:

   ```bash
   flutter analyze
   ```

5. Запустити застосунок:

   ```bash
   flutter run
   ```

Для запуску у браузері Chrome:

```bash
flutter run -d chrome
```

## Організація стану

| Дані                                      | Тип стану                | Де зберігаються                         |
| ----------------------------------------- | ------------------------ | --------------------------------------- |
| Вибраний, але ще не підтверджений варіант | Локальний стан           | `setState` у `QuizScreen`               |
| Підтверджені відповіді                    | Спільний стан застосунку | `QuizProgress`                          |
| Індекс поточного питання                  | Спільний стан застосунку | `QuizProgress`                          |
| Ознака підтвердження відповіді            | Спільний стан застосунку | `QuizProgress`                          |
| Кількість правильних відповідей           | Обчислювані дані         | Обчислюється з підтверджених відповідей |
| Відсоток правильних відповідей            | Обчислювані дані         | Обчислюється на основі результату       |
| Перелік помилок                           | Обчислювані дані         | Формується на екрані результатів        |
| Питання та варіанти відповідей            | Незмінні дані            | `quiz_questions.dart`                   |

## Етапи реалізації

### Етап 1 - Lifting State Up

Спільний стан винесено до спільного предка віджетів. Дані передаються через конструктори, а зміни стану - через callback-функції. Для локального стану використовується `setState`.

Git-тег: `stage-1-lifting`

### Етап 2 - InheritedNotifier

Спільний стан винесено до класу `QuizProgress`, який використовує `ChangeNotifier`. Для доступу до стану з різних віджетів створено `QuizProgressScope` на основі `InheritedNotifier` зі статичним методом `of(context)`.

Це дає змогу отримувати спільний стан без передавання його через усі проміжні віджети.

Git-тег: `stage-2-inherited`

## Перебудова віджетів

Для відстеження змін стану в класі `QuizProgress` використовуються повідомлення `debugPrint`.

Після зміни спільного стану `ChangeNotifier` повідомляє слухачів, а залежні від нього віджети можуть перебудовуватися. Локальна зміна вибраної відповіді виконується через `setState`.

Повідомлення про перебудову віджетів можна переглянути в консолі налагодження під час запуску застосунку.
